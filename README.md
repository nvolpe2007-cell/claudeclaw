# Volpe Web Development

Single-page marketing site for Volpe Web Development, a freelance web developer.

- Static, dependency-free HTML/CSS/JS (`index.html`) — no build step
- Black-and-white theme with an animated white-neon fox mark in the hero
- Scroll-revealed case studies with eased transitions
- Call/text-back CTAs throughout (`tel:` / `sms:` links)

## Running locally

Just open `index.html` in a browser, or serve the directory:

```
python3 -m http.server
```

## Deploying

This is a static site — drop `index.html` on any static host (GitHub Pages, Netlify, Vercel, S3, etc.).
